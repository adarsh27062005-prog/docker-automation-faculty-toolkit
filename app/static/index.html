Live repository evaluation, submission date tracking & Excel reporting

⇪
Drag & drop student roster Excel file here, or click to browse
Only .xlsx files are supported (max 2 MB, up to 500 students)

Required Roster Format:

  • Header row with columns: Roll No (optional), Name (optional), and Docker ID (mandatory).
  • Docker ID can be a username (e.g. alice) or full profile URL (e.g. https://hub.docker.com/u/alice).
  • Files are parsed in memory on the server and are never saved to disk.
